# Provably Fair Verification System

NOVA Gaming implements standard cryptographic provably fair mechanisms across all game plug-ins using HMAC-SHA256.

## How It Works
1. **Server Seed**: A cryptographically random 32-byte string generated by the server.
2. **Server Seed Hash**: SHA-256 hash of the server seed shown to the player before any bet is placed.
3. **Client Seed**: A string chosen by the player (or auto-generated).
4. **Nonce**: A counter starting at 0 that increments with every bet made using the active seed pair.

## Formula
$$\text{HMAC-SHA256}(\text{serverSeed}, \text{clientSeed} : \text{nonce})$$

The first 4 bytes (8 hex characters) are converted to an integer and normalized to $[0, 1)$ float values to derive deterministic outcomes (coin side, dice roll 0-100, crash point multiplier, roulette number 0-36).
